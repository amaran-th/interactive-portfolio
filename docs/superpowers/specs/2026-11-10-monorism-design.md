# 모노리즘 설계

- 날짜: 2026-11-10
- 대상: `apps/services`
- 범위: 새 도구 4종 요청 중 B 묶음(3D 뒤집기 칩 모자이크). A 묶음(웹 유틸 3종)은 `2026-11-10-web-utils-design.md`.

## 목표

얇은 원형 칩이 지그재그로 깔린 판을 3D로 보여 주고, 칩을 뒤집거나 빼고 놓아서 모자이크 그림을 만드는 창작 도구를 만든다. 칩은 앞면과 뒷면 색이 다르고, 뒤집을 때 "딱" 소리가 난다.

### 성공 기준

- `/monorism`이 열리고, 메인의 창작 카테고리·sitemap에 나온다.
- 64×64 판(4,096칩)에서 드래그로 뒤집어도 끊김 없이 움직인다(데스크톱 Chrome 기준 60fps 근처).
- 새로고침해도 판이 그대로 남는다.
- 판 로직은 `node:test`로, 화면 동작은 Playwright로 확인한다.

## 1. 판과 칩

### 판 크기·배치

- 크기: 작게 24×24, 보통 40×40, 크게 64×64. '새 판'을 만들 때 고르고, 기본은 보통.
- 지그재그 배치:
  - 홀수 줄(0부터 셈)은 오른쪽으로 반 칸 밀린다.
  - 줄 간격은 칩 지름 × √3/2라서 칩이 벌집처럼 촘촘히 맞물린다.
- 판 바닥은 칩보다 어두운 무광 단색 판이다. 칩을 빼면 흔적 없이 바닥만 보인다(2026-11-10 사용자 요청으로 빈 자리 홈 표시를 뺐다).

### 칩 상태

칩 자리마다 상태가 셋이다.

- `0` 빈 자리
- `1` 앞면이 위
- `2` 뒷면이 위

새 판은 모든 자리가 `1`이다.

### 색

- 판 전체가 앞면 색 하나, 뒷면 색 하나를 쓴다.
- 미리 만든 조합 5가지와 '직접 고르기'(색 입력 두 개)가 있다. 바꾸면 바로 반영된다.

| 조합 | 앞면 | 뒷면 |
|---|---|---|
| 은·금 | `#c9ced6` | `#d8b24a` |
| 분홍·민트 | `#f4a7c0` | `#8fdcc8` |
| 검정·흰색 | `#26282c` | `#f2f2ee` |
| 남색·주황 | `#24407a` | `#f08a3c` |
| 보라·노랑 | `#7b5cc4` | `#f5d547` |

- 칩 재질은 금속 광택이 조금 있는 스팽글 느낌이다(`MeshStandardMaterial`, metalness 약 0.6, roughness 약 0.35, 환경광 반사).

## 2. 도구와 조작

### 도구 3가지

도구 막대에서 고르고, 단축키는 `1`·`2`·`3`이다.

| 도구 | 앞/뒷면 칩 | 빈 자리 |
|---|---|---|
| 뒤집기(기본) | 반대 면으로 | 그대로 |
| 빼기 | 빈 자리로 | 그대로 |
| 놓기 | 그대로 | 앞면 칩을 놓는다 |

### 클릭과 드래그

- 왼쪽 버튼(터치는 한 손가락)으로 누르면 그 칩에 현재 도구를 적용한다.
- 누른 채 끌면 지나간 경로의 칩에 차례로 적용한다.
  - 한 번 긋는 동안 같은 칩에는 한 번만 적용한다. 왔다 갔다 해도 다시 뒤집히지 않는다.
  - 포인터 이동 사이를 칩 지름의 1/3 간격으로 보간해, 빠르게 그어도 중간 칩이 빠지지 않는다.
- 판 밖을 누르거나 지나가는 부분은 무시한다.

### 확대·이동

- 데스크톱:
  - 휠로 확대·축소한다. 포인터 위치를 기준으로 한다.
  - 오른쪽 버튼이나 가운데 버튼으로 끌면 이동한다.
- 터치: 두 손가락으로 확대·축소와 이동을 한다. 두 번째 손가락이 닿으면 진행 중인 긋기는 그 시점에서 끝낸다.
- '화면 맞춤' 버튼으로 판 전체가 보이게 돌아간다.
- 확대 범위: 화면 맞춤 배율의 1배~8배.

### 시점

- 원근 카메라로 판을 위에서 약 25° 기울여 본다. 시점 회전은 넣지 않는다.

### 편집 기록

- 실행 취소/다시 실행: Ctrl/⌘+Z, Ctrl/⌘+Shift+Z, 도구 막대 버튼
- 긋기 한 번, '전체 뒤집기', '모두 채우기', '모두 빼기'가 각각 한 단계다. 최대 100단계까지 보관한다.
- 기록은 저장하지 않는다. 새로고침하면 기록은 비고 판만 남는다.
- '새 판'을 만들기 전에 확인 창을 띄운다. 새 판을 만들면 기록이 비워진다.

## 3. 움직임과 소리

### 애니메이션

- 뒤집기: 칩이 0.08만큼 떠오르며 가로축으로 180° 돈다. 0.2초, ease-out.
- 빼기: 칩이 떠오르며 작아져 사라진다. 0.15초.
- 놓기: 위에서 내려앉으며 커진다. 0.15초.
- 드래그로 여러 칩을 바꾸면 칩마다 자기 차례에 애니메이션을 시작해서 물결처럼 보인다.
- `prefers-reduced-motion`이면 애니메이션 없이 바로 바꾼다.

### 소리

녹음 파일 없이 Web Audio로 만든다.

- 뒤집기 "딱": 짧은 노이즈 버스트(대역 통과 필터 약 3kHz, 감쇠 약 40ms)에 짧은 고음 클릭을 섞는다.
- 빼기·놓기: 같은 구조에 음높이만 낮춘다.
- 칩마다 음높이를 ±10% 안에서 무작위로 바꾼다.
- 드래그 중에는 소리를 최소 30ms 간격으로만 낸다.
- `AudioContext`는 첫 사용자 입력 때 만든다(브라우저 자동 재생 정책).
- 음소거 버튼이 있고, 음소거 여부는 저장한다.

## 4. 저장과 내보내기

### 자동 저장

- localStorage 키 `monorism-board`, 값은 JSON:

```json
{
  "v": 1,
  "w": 40,
  "h": 40,
  "front": "#c9ced6",
  "back": "#d8b24a",
  "cells": "<base64>",
  "muted": false
}
```

- `cells`는 칩 상태를 한 칸에 2비트씩 담아 base64로 인코딩한다.
- 바뀐 뒤 500ms 동안 더 바뀌지 않으면 저장한다.
- 읽을 때 형식이 맞지 않으면(버전·크기·길이 불일치) 무시하고 새 판으로 시작한다. 이때 예외를 내지 않는다.
- `apps/services/app/privacy/page.tsx`의 `STORAGE_ITEMS`에 이 키를 추가한다.

### PNG로 저장

- 지금 화면의 3D 장면을 PNG로 내려받는다. 파일명은 `monorism-YYYYMMDD-HHmm.png`.
- 렌더러는 `preserveDrawingBuffer: false`로 두고, 저장할 때 한 번 렌더한 직후 `toBlob`으로 읽는다.

## 5. 구조

### 라이브러리

- `three`를 서비스 앱 의존성에 추가한다.
- 이 도구 컴포넌트에서만 import하므로 다른 페이지 번들에는 들어가지 않는다.
- 환경광 반사에는 `three/examples/jsm/environments/RoomEnvironment.js`를 쓴다.

### 파일

`components/works/10_Monorism/`:

| 파일 | 역할 |
|---|---|
| `board.ts` | 판 상태·도구 적용·긋기·실행 취소·직렬화. 순수 함수, import 없음, `node:test` 대상 |
| `layout.ts` | 지그재그 좌표 계산: 칸 → 판 위 위치, 판 위 점 → 칸(가장 가까운 칩 중심), 경로 보간. 순수 함수, `node:test` 대상 |
| `palettes.ts` | 색 조합 목록 |
| `useChipScene.ts` | three.js 장면 생성·정리, InstancedMesh 갱신, 애니메이션 루프, 카메라 확대·이동, 화면 좌표 → 판 위 점(광선과 판 평면의 교점) |
| `chipSound.ts` | Web Audio "딱" 소리, 간격 제한, 음소거 |
| `Monorism.tsx` | 도구 막대·색·크기·저장 UI, 포인터 이벤트를 판 로직으로 연결 |

라우트는 `app/monorism/page.tsx`와 `guide.ts`. `lib/tools.ts`의 `TOOLS`에 `category: "creative"`로 등록한다.

### 렌더링

- 칩 하나는 얇은 원기둥이다(`CylinderGeometry`, 반지름 0.46, 두께 0.06, 둘레 32분할).
- 그룹별 재질:
  - 옆면: 두 색의 중간쯤 되는 어두운 색
  - 윗면: 앞면 색
  - 아랫면: 뒷면 색
- 칩 전체를 `InstancedMesh` 하나로 그린다. 상태는 인스턴스 행렬로 나타낸다.
  - 뒷면이면 X축으로 180° 회전한다.
  - 빈 자리면 크기를 0으로 둔다.
  - 애니메이션 중인 칩만 매 프레임 행렬을 갱신한다.
- 칩 판정은 레이캐스트 대신 판 평면 교점 → `layout.ts`의 칸 계산으로 한다. 4,096개 인스턴스를 훑지 않아 가볍다.
- 화면 크기는 `ResizeObserver`로 따라간다. 픽셀 비율은 최대 2로 제한한다.
- 언마운트할 때 geometry·material·texture·renderer를 dispose한다.

## 6. 안내 문구

- `guide.ts`(합니다체): 도구 3가지, 클릭·드래그, 확대·이동(마우스·터치), 색, 실행 취소, 자동 저장·PNG, 소리·음소거, FAQ(저장 위치, 소리가 안 나요, 큰 판이 느려요).
- `TOOLS` 항목(해요체)의 `title`은 "모노리즘", 태그는 모자이크·스팽글·도트·3D·픽셀아트 등이다.

## 7. 검증

1. `node:test`:
   - `layout`:
     - 칸 → 위치 → 칸 왕복이 판 전체에서 일치한다.
     - 두 칩 사이 경계점은 가까운 칩으로 간다.
     - 판 밖의 점은 null이다.
     - 홀수 줄이 반 칸 밀려 있다.
     - 보간 간격이 지름의 1/3 이하다.
   - `board`:
     - 세 도구 각각의 상태 전이
     - 한 긋기에서 같은 칸은 한 번만 적용된다.
     - 실행 취소·다시 실행, 100단계 제한
     - 전체 뒤집기·모두 채우기·모두 빼기
     - 직렬화 왕복과, 잘못된 저장값은 null
2. `npm run lint`, `npm run build` 통과. sitemap에 `/monorism`이 있다.
3. Playwright(헤드리스 Chromium, WebGL은 SwiftShader):
   - 판 중앙을 클릭하면 저장값에서 그 칸이 바뀐다.
   - 가로로 끌면 지나간 줄의 칸이 바뀐다.
   - Ctrl+Z로 되돌린다.
   - 빼기·놓기 도구가 동작한다.
   - 새로고침 후 상태가 유지된다.
   - PNG 저장이 파일을 내려받는다.
   - 모바일 375px 폭에서 가로 스크롤이 없다.
   - 콘솔 오류가 없다.
4. 직접 확인(사용자):
   - 소리와 애니메이션 느낌
   - 64×64 판의 프레임
   - 터치 기기에서 두 손가락 확대·이동
