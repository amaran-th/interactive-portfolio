# 자산 없는 비주얼 노벨 — 3-Work 생태계 설계 문서

## 개요

`비주얼 노벨 메이커`(Work #2)는 현재 캐릭터/배경 이미지와 BGM/SFX 오디오 파일을 사용자가 직접 업로드해 IndexedDB에 Blob으로 저장한다. 이 방식은 이 프로젝트의 취지(서버·외부 인프라 없이, 가벼운 데이터만으로 최대한의 가치를 뽑는다)와 맞지 않는다.

대안으로 파일 업로드 대신 **텍스트로 표현 가능한 데이터**(픽셀 그리드, 노트 시퀀스)로 자산을 만들고 재생 시점에 캔버스/Web Audio로 합성하는 방식을 도입한다. 이를 위해 서로 다른 목적을 가진 세 개의 Work가 하나의 공유 자산 라이브러리로 연결된다.

- **픽셀아트 메이커** (신규 Work) — 범용 픽셀아트 편집기. 컨셉과 상세 설계는 아래 [픽셀아트 메이커 상세 설계](#픽셀아트-메이커-빌드-순서-1번--상세-설계) 참고.
- **비트 음악 메이커** (신규 Work) — BGM/SFX 패턴 제작. 고유 컨셉도 별도 세션에서 다룬다.
- **비주얼 노벨 메이커 v2** (기존 Work #2 개편) — 라이브러리에서 자산을 "선택"해 컷을 구성. 자체 업로드 기능은 제거.

각 메이커는 자기 목적을 위해 독립적으로도 쓸 수 있는 완결된 Work이며, 비주얼 노벨 메이커는 그 산출물을 소비하는 대상 중 하나일 뿐이다. 이 문서는 **자산 계약(데이터 형태)과 세 Work의 역할 분담**만 다룬다. 각 메이커의 고유 컨셉과 상세 UI는 이후 별도 스펙에서 확정한다.

## 공유 자산 라이브러리

Works 전역에서 공유하는 localStorage 기반 라이브러리를 둔다. 위치는 개별 Work 폴더가 아닌 공용 위치:

```
app/(portfolio)/playground/_sections/Works/_shared/assetLibrary.ts
```

```ts
type PixelArt = {
  id: string;
  name: string;
  width: number;
  height: number;
  palette: string[];   // hex 색상, 작품당 개수 제한(예: 16색 이하)
  pixels: number[];    // length = width*height, palette 인덱스, -1 = 투명
};

type BeatTrack = {
  wave: "square" | "triangle" | "noise";
  steps: (string | null)[]; // 음정(e.g. "C4") 또는 null(무음), 트랙 내 스텝 수 동일
};

type BeatPattern = {
  id: string;
  name: string;
  type: "bgm" | "sfx"; // bgm = 루프 재생, sfx = 1회 재생
  bpm: number;
  tracks: BeatTrack[];
};

type AssetLibrary = {
  pixelArt: PixelArt[];
  beatPatterns: BeatPattern[];
};
```

- 픽셀아트/음악 메이커가 "저장"하면 이 라이브러리(localStorage 키 하나)에 추가된다.
- 비주얼 노벨 메이커는 파일 선택 대신 이 라이브러리에서 골라 쓴다(썸네일/재생 미리듣기 그리드에서 선택하는 라이브러리 브라우저 UI).
- 전부 숫자/문자열 배열이므로 Blob 대비 데이터가 훨씬 가볍고, `JSON.stringify` 결과 자체가 내보내기/공유 포맷이 된다.
- 자산 삭제(픽셀아트/패턴 삭제)는 이 설계 범위에서는 다루지 않는다 — 각 메이커 세부 설계에서 정의.

## 픽셀아트 데이터 계약

- 해상도는 용도 구분 없는 범용 프리셋 목록(예: 16x16 / 32x32 / 64x64 / 160x90) 중 제작자가 선택. 픽셀아트 메이커는 캐릭터/배경 구분을 모르는 범용 툴이다.
- 팔레트는 자유 색상(hex)이되 작품당 색상 개수를 제한한다(예: 16색 이하).
- 비주얼 노벨 메이커 쪽에서 캐릭터 1명이 여러 표정 이미지(예: 기본/기쁨/슬픔)를 가질 수 있다 — 기존 `Character.images: CharacterImage[]` 구조를 유지하되, 각 이미지가 파일 URL 대신 `PixelArt.id` 참조로 바뀐다. "표정"은 VN 메이커 자체 데이터 모델의 개념일 뿐, 픽셀아트 메이커·`PixelArt` 타입에는 존재하지 않는다.

## 음악 데이터 계약

- 스텝 시퀀서(트래커) 방식: BPM + 트랙별 파형(`square`/`triangle`/`noise`) + 스텝 배열(음정 또는 무음).
- BGM(루프)과 SFX(1회 재생)를 `BeatPattern.type`으로 구분 — 기존 `AudioTrackType`("bgm"/"sfx") 구조를 그대로 승계한다.
- 재생은 Web Audio API로 그 자리에서 합성한다. 오디오 파일 저장은 전혀 없다.

## 비주얼 노벨 메이커 v2에서 바뀌는 부분

기존 파일: `app/(portfolio)/playground/_sections/Works/2_RoughVisualNovelMaker/`

- `types.ts` — `CharacterImage.imageUrl` / `Background.imageUrl` / `AudioTrack.audioUrl` → 각각 `PixelArt.id` / `BeatPattern.id` 참조로 교체
- `AssetUploader.tsx`(파일 업로드 UI) → 공유 라이브러리에서 자산을 고르는 라이브러리 브라우저 컴포넌트로 교체
- `imageStore.ts`(IndexedDB Blob 저장) — 삭제. 픽셀아트는 `assetLibrary.ts`가 대체
- `VNDisplay.tsx` / `PlayScreen.tsx` — `<img>` 렌더링 대신 픽셀아트 데이터를 캔버스에 그리는 렌더러로, 오디오 `<audio>` 태그 대신 Web Audio 합성 재생으로 교체
- 프로젝트 데이터(컷 배열 등) 자체는 참조 id들만 담으므로 지금보다 훨씬 가벼워진다

## 빌드 순서

1. 픽셀아트 메이커 (+ 공유 자산 라이브러리 `pixelArt` 부분 최초 구현)
2. 비트 음악 메이커 (+ 라이브러리 `beatPatterns` 부분 추가)
3. 비주얼 노벨 메이커 v2 개편 (라이브러리 소비 + 업로드 로직 제거)

앞의 두 Work가 먼저 존재해야 실제 자산이 라이브러리에 쌓이고, VN 메이커의 라이브러리 브라우저 UI를 실물 데이터로 검증할 수 있다.

## 픽셀아트 메이커 (빌드 순서 1번) — 상세 설계

### 컨셉

게임적 훅 없이 **PC/모바일 바탕화면 은유**를 UI로 쓰는, 실사용 가능한 범용 픽셀아트 편집기. 캐릭터·표정 같은 도메인 개념을 전혀 모르는 범용 툴이며, 저장한 작품들이 데스크탑 아이콘처럼 보이고 더블클릭하면 편집창이 열린다. 여러 Work에 걸친 "캐릭터 표정 세트" 같은 묶음 개념은 소비하는 쪽(비주얼 노벨 메이커 등)이 라이브러리의 개별 조각 여러 개를 골라 자체 데이터 모델로 구성한다.

### 홈 화면 (데스크탑)

- 저장된 픽셀아트가 아이콘(썸네일)으로 표시된다. 그리드에 스냅되지만 자유롭게 드래그해 재배치할 수 있고, 위치는 저장된다 — 이 위치 정보는 공유 자산 라이브러리(`PixelArt` 타입)가 아니라 이 Work 자체의 로컬 레이아웃 데이터(`id → {x, y}`)로 별도 저장한다.
- 더블클릭 → 편집창 열기
- 배경 우클릭 → 컨텍스트 메뉴 "새로 만들기" → 크기 프리셋 선택 후 편집기로 진입
- 아이콘 우클릭 → 이름 바꾸기 / 내보내기(PNG·SVG·JSON·JPG) / 복제(독립 사본)
- **다중 선택**: 빈 공간 드래그로 박스 선택 + `Ctrl`/`Shift`+클릭으로 개별 추가/제외. 선택된 여러 아이콘은 함께 드래그해 이동 가능
- 구석에 휴지통 아이콘. 아이콘(들)을 휴지통으로 드래그하면 **삭제 확인 모달**이 뜨고, 확인해야 실제 삭제됨(즉시 삭제 아님, 복원 기능은 없음)

### 편집기 화면

캔버스 + 도구바 + 팔레트 패널 + import 패널로 구성.

- 도구: 펜슬 / 지우개 / 채우기(버켓) / 스포이트, 도형(직선·사각형·원), 좌우/상하 미러 드로잉, 선택·이동·복사-붙여넣기, 자동 선택(색상 기준 / 알파값 기준)
- 단축키: `B` 펜슬 · `E` 지우개 · `G` 채우기 · `I` 스포이트 · `U` 도형 · `M` 선택 · `V` 이동 · `W` 자동선택 · `Ctrl+Z/Y` 실행취소·다시실행 · `Ctrl+C/V` 복사·붙여넣기 · `Shift+H/V` 미러 토글 · `Space`+드래그 팬 · 스크롤/`Ctrl+`스크롤 줌
- 캔버스 크기는 범용 프리셋 목록(16x16 / 32x32 / 64x64 / 160x90 등, 용도 구분 없음)에서 생성 시 선택
- 실행취소/다시실행 기본 제공

### 이미지 import (사진 → 픽셀아트 변환)

기존 툴들의 "안티에일리어싱 때문에 중간색이 잔뜩 섞이는" 문제 해결이 핵심.

- 이미지를 드래그/업로드하면 픽셀화 미리보기 화면으로 진입 (되돌릴 수 없는 즉시 변환이 아니라, 미리보기 확인 후 확정)
- 조절 가능한 옵션: 픽셀 크기(다운샘플링 해상도), 안티에일리어싱 on/off
- 색상 후처리: 추출된 색상을 대표색 개수로 강제 통합 — 유사 색상 자동 병합 + 특정 색상끼리 수동 병합
- 확정 시 팔레트+픽셀 인덱스 배열로 캔버스에 반영

### 저장 & 내보내기

- **로컬 저장** → 공유 자산 라이브러리의 `pixelArt` 컬렉션에 기록 → 데스크탑에 아이콘으로 즉시 표시 → 비주얼 노벨 메이커 등 다른 Work에서 선택해 재사용 가능
- **파일 내보내기**: PNG(래스터) / SVG(픽셀별 `<rect>`, 벡터) / JSON(재편집 가능한 원본 데이터) / JPG(요청에 따라 제공하되, 손실 압축으로 팔레트 경계가 흐려질 수 있음을 UI에서 안내)

## 공통 요구사항: 미저장 변경사항 경고

세 Work 모두 편집 중(캐릭터/배경/음악 제작 또는 컷 구성 등) 탭을 새로고침·닫으려 하면 브라우저 기본 `beforeunload` 확인창이 뜨도록 한다. 커스텀 텍스트는 브라우저가 허용하지 않으므로 기본 확인창 그대로 사용한다.

- 공용 훅: `app/(portfolio)/playground/_sections/Works/_shared/useUnsavedChangesWarning.ts` — `hasUnsavedChanges: boolean`을 받아 `beforeunload` 리스너를 등록/해제
- "편집 중"의 정의는 Work마다 다르다: 비주얼 노벨 메이커는 캐릭터·배경·오디오 트랙이 하나라도 있거나 컷에 내용이 있으면 편집 중으로 간주(구현 완료). 픽셀아트/비트 음악 메이커는 캔버스·시퀀서에 저장되지 않은 작업이 있을 때가 기준이며, 각 Work의 상세 설계에서 "편집 중" 조건을 구체적으로 정의한다.
