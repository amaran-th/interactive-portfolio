# 비주얼 노벨 스튜디오 만화·낙서 테마 리디자인 — 설계 문서

## 개요

`비주얼 노벨 스튜디오`(Work #2)는 최근 "잉크 매뉴스크립트" 라이트 테마로 리디자인됐다. 이번에는 그 위에 다시 새 테마를 입힌다 — 이 Work의 실제 미리보기 이미지·파비콘(`public/playground/visual-novel-studio.png`, `.svg`)이 보여주는 **만화·낙서(웹툰) 스타일**을 편집 UI에 반영한다.

이미지는 손그림풍 캐릭터 두 명이 말풍선으로 "HELLO!"/"Hi." 대화를 나누는 장면이다: 두꺼운 검정 아웃라인, 평평한 색면, 진회색 배경, 회백색 말풍선, 빨강·파랑 후드 캐릭터.

이 문서는 **비주얼 재디자인 범위**만 다룬다. 기능 로직은 바꾸지 않는다 — 이전 두 차례의 VN 스튜디오 리스킨(스펙: `2026-07-18-vn-studio-asset-picker-design.md`의 리소스 선택 기능, `2026-07-19-vn-studio-light-mode-design.md`의 라이트모드)과 동일한 원칙.

## 범위: 편집 UI만, VN 스테이지는 제외

사용자가 명시적으로 확인한 범위 구분: 이 만화 테마는 **편집 UI**(홈 화면, 리소스 편집, 컷 편집기의 컨트롤류, 플레이 화면의 헤더/컷 목록)에만 적용된다. **`VNDisplay.tsx`(실제 배경·캐릭터·대사박스가 나오는 VN 스테이지)는 이번 작업에서 전혀 건드리지 않는다** — 사용자가 그린 픽셀아트(배경·캐릭터)와 어울리지 않을 수 있는 만화풍 아웃라인·컬러를 스테이지에 넣지 않기 위해서다. `VNDisplay.tsx`는 지금의 잉크 매뉴스크립트 스타일(흰 배경, 어두운 반투명 대사박스 예외 포함) 그대로 남는다.

`EditorScreen.tsx`/`PlayScreen.tsx`는 내부에서 `<VNDisplay ... />`를 호출하지만, 그 호출부와 `VNDisplay.tsx` 자체는 건드리지 않는다 — 이 두 파일에서 바뀌는 건 그 주변 UI(헤더, 컷 목록, 배경/캐릭터/발화자 선택 칩, 대사 입력창 등)뿐이다.

## 1. 색상 팔레트 (이미지에서 직접 추출)

`public/playground/visual-novel-studio.png`에서 픽셀 샘플링으로 추출한 정확한 값:

| 역할 | 값 |
|---|---|
| 페이지 배경 | `#818181` (진회색) |
| 카드/패널 배경 | `#d9d9d9` (회백 — 이미지의 말풍선 색과 동일) |
| 아웃라인 | `#000000`, 두께 2px 고정 |
| 강조색(파랑 후드) | `#264986` |
| 위험/삭제(빨강 후드) | `#ac1717` |

Tailwind는 임의값 문법(`bg-[#818181]`, `border-[#264986]` 등)으로 이 정확한 hex를 그대로 쓴다 — 근사한 기본 팔레트 색상(`bg-gray-500` 등)으로 대체하지 않는다.

### 텍스트 색상 규칙

- 카드(`#d9d9d9`) 위의 텍스트: `text-black` (대비 충분, 이미지의 "HELLO!"/"Hi." 텍스트도 어두운 검정)
- 페이지 배경(`#818181`) 위에 직접 놓이는 굵은 제목: `font-bold text-black` — 검정 대 `#818181`의 대비비는 약 4.6:1로 굵은 제목 텍스트에 충분하다
- 보조/설명 텍스트(카드 위): `text-gray-700` — 회백 카드 위에서 충분히 읽히면서 본문보다 한 단계 옅게

## 2. 모서리 — 이전 테마와 정반대로 "둥긂 환영"

직전 잉크 매뉴스크립트 테마의 "모든 `rounded-*` 제거" 규칙을 뒤집는다. 요소 종류별로 아래 라운딩을 일관되게 적용한다:

| 요소 종류 | 라운딩 |
|---|---|
| 카드/패널/모달 패널 | `rounded-2xl` |
| 버튼(사각형 형태), 입력창, 텍스트에어리어 | `rounded-lg` |
| 칩(선택 가능한 태그), 원형 아이콘 버튼, 배지 | `rounded-full` |

(회색·검정으로 이뤄진 이미지 속 캐릭터 머리가 동글동글한 원인 것처럼, 칩·아이콘류는 완전히 둥글게.)

## 3. 테두리 — 직선 + 두꺼운 검정

모든 카드·버튼·입력창·칩의 테두리를 `border-2 border-black`으로 통일한다. 손그림처럼 살짝 삐뚤빼뚤한(wobbly) 효과는 넣지 않는다 — 구현 안정성을 위해 직선 테두리 + 두꺼운 검정색만으로 "만화 아웃라인" 느낌을 낸다(사용자 확인 완료).

## 4. 강조 2단계 패턴 (이전 두 테마와 같은 틀 재사용)

| 역할 | 패턴 |
|---|---|
| 강한 강조(CTA, 선택된 탭/컷 번호) | `bg-[#264986] text-white` |
| 중간 강조(선택된 칩) | `bg-[#264986]/10 text-[#264986]` (테두리는 칩 자체의 `border-2 border-black` 유지) |
| 비선택 칩(아웃라인) | `border-2 border-black text-gray-700 hover:bg-black/5` |
| 확정 삭제 버튼 | `bg-[#ac1717] text-white` |
| 상시 노출 삭제(아이콘/텍스트) | `text-gray-700 hover:bg-red-50 hover:text-[#ac1717]` |

발화자 칩의 `bg-blue-500`(캐릭터)·`bg-amber-500`(나레이션)는 지난 라이트모드 리디자인 때부터 의미색으로 유지돼 온 것 — 이번에도 손대지 않는다.

## 5. 폰트

`Mona12`/`Mona12-Bold` 도트 폰트를 그대로 유지한다(사용자 확인 완료 — 손그림풍 폰트로 바꾸지 않는다). `_shared/fonts.ts`에서 그대로 가져다 쓰는 기존 구조 변경 없음.

## 6. 적용 범위 (파일별)

| 파일 | 변경 내용 |
| --- | --- |
| `HomeScreen.tsx` | 슬롯 카드, 헤더 만화 테마 적용 |
| `VisualNovelStudio.tsx` | 셸 배경·리소스 편집 화면 자체 UI(내부에서 렌더링하는 `AssetUploader`는 별도 파일) |
| `AssetUploader.tsx` | 탭 바, 캐릭터/배경/사운드 폼과 카드 |
| `ResourcePicker.tsx` | 모달 패널(오버레이 스크림 `bg-black/70`은 계속 유지 — 어느 테마에서도 바뀐 적 없는 표준 모달 관례) |
| `EditorScreen.tsx` | 헤더, 컷 목록, 배경/캐릭터/발화자/텍스트이펙트 선택 칩, 대사 입력창, 음악 섹션. **`<VNDisplay>` 호출부와 그 컴포넌트 자체는 미변경.** |
| `PlayScreen.tsx` | 헤더, 컷 목록. **`<VNDisplay>` 호출부와 그 컴포넌트 자체는 미변경.** |

`VNDisplay.tsx`는 파일 목록에 없다 — 이번 계획에서 아예 열지 않는다.

## 범위 밖

- `VNDisplay.tsx`(VN 스테이지) 자체의 재디자인 — 명시적으로 이번 범위 밖.
- 손그림처럼 삐뚤빼뚤한(wobbly) 테두리 효과 — 사용자가 명시적으로 보류, 직선 테두리로 확정.
- 정확한 Tailwind 클래스 목록(파일별 상세 치환)은 구현 계획(writing-plans) 단계에서 확정한다.
