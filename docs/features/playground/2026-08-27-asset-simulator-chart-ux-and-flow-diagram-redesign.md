# 자산 시뮬레이터 차트 UX 개선과 자금 흐름도 재설계

자산 시뮬레이터의 여러 차트에 걸쳐 hover 인터랙션을 일관되게 강화하고, 자금 흐름도(FlowDiagram)의 레이아웃을 배치 원칙부터 다시 세웠다.

## 그래프 hover 강조

기존에는 그래프를 hover해도 세로 기준선과 점 마커가 타임라인 슬라이더로 선택한 달(selectedMonth)에만 고정돼 있어, 실제로 마우스가 가리키는 시점의 데이터가 그래프 위에 드러나지 않았다. 자산 비교, 자산(스택 영역), 수입/지출 세 그래프 모두에 hover 전용 가이드 라인과 계열별(또는 자산별) 색상 점 마커를 추가해, hover 위치의 실제 데이터가 즉시 시각적으로 보이도록 했다. 선택된 달을 나타내는 기존 표시는 그대로 두고 별도 레이어로 얹는 방식이라 서로 간섭하지 않는다.

자산 비교 그래프의 hover 툴팁도 특정 자산 하나만 보여주던 걸 확장해, 해당 시점 총자산과 막대를 구성하는 전체 자산 내역을 함께 보여주도록 바꿨다.

## 시나리오 탭/버튼 높이 통일

시나리오 칩(`<li>`) 안에 있는 이름수정·삭제 아이콘 버튼이 자체 패딩을 가지면서, 칩 전체 높이가 "현재 탭 복제"·"+ 새 시나리오" 같은 옆 버튼들보다 커 보이는 문제가 있었다. 모든 요소를 `h-7`로 고정해 한 줄에서 높이가 어긋나지 않게 정리했다.

## 자금 흐름도 배치 재설계

자금 흐름도는 세 차례에 걸쳐 점진적으로 재설계됐다.

1. **1차**: 이체 대상(예: 적금)과 지출이 같은 오른쪽 열에 있어 시각적으로 같은 카테고리처럼 보이는 문제 — 색상을 카테고리별(수입=초록/지출=빨강/이체=호박)로 분리하고 클러스터 간 간격을 벌림.
2. **2차**: 그래도 헷갈린다는 피드백에 따라, 이체 대상 자산은 지출과 달리 실제 자산이라는 점에 착안해 배치 자체를 재구성. 수입/지출은 기본 자산의 좌우에 두고, 이체로 늘어나는 자산들은 기본 자산과 **같은 열**에서 아래로 뻗어나가는 구조로 바꿨다. 같은 열에 놓인 자산 박스는 화살표에 표시되는 이번 달 이체액이 아니라 그 자산의 실제 잔액을 보여준다(현금 박스와 동일한 정보 성격).
3. **3차(레이아웃 유연화)**: 이체 대상이 3개 이상이면 같은 열에 단순히 쌓이면서 박스끼리 딱 붙고 화살표가 겹치거나 아예 안 보이는 문제가 발생. 각 이체 화살표를 현금 바로 아래로 직행시키는 대신, 옆의 공통 "레일(rail)"로 살짝 비켜났다가 각자의 박스 앞에서 꺾어 들어가는 독립된 elbow path(M-L-L-L-L)로 그려 서로 절대 겹치지 않게 했다. 박스 사이 간격(`ASSET_GAP`)과 SVG 캔버스 높이도 이체 대상 개수에 맞춰 동적으로 계산해, 자산이 몇 개든 유연하게 늘어나도록 했다.

박스 색상도 개편 과정에서 두 갈래로 갈렸다: 화살표는 카테고리 색(수입/지출/이체)을 유지하되, 목적지 박스는 그게 실제로 무엇인지(자산이면 자산 고유색, 지출이면 카테고리색)를 드러내도록 분리했다.
