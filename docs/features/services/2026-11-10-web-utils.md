# 웹 유틸 3종: 문자 인코딩 변환기 · 색상 스포이트 · 팔레트 추출기

서비스 포털에 설치·가입 없이 쓰는 작은 유틸 3개를 추가했다. 모두 브라우저 안에서만 계산하고 아무것도 저장하지 않는다. 처음에는 텍스트, 개발·웹 카테고리에 나눠 넣었다가, 카테고리가 많아지는 것을 피하려고 생산성에 모았다.

## 문자 인코딩 변환기 (`/text-encoding`)

- **글자 → 코드**:
  - 코드포인트마다 한 줄씩 보여 준다: 유니코드, UTF-8, UTF-16(BE, 16비트 단위), EUC-KR, ASCII.
  - 표현할 수 없으면 "없음"으로 표시한다.
  - 표는 앞 2,000자까지만 그리고, 인코딩별 전체 바이트열은 끝까지 계산한다.
- **코드 → 글자**:
  - `EA B0 80`, `EAB080`, `0xEA,…`, `\xEA…` 같은 바이트열과 `U+AC00`, `가`, `&#44032;` 같은 코드포인트를 읽는다.
  - 잘못된 입력은 몇 번째 값에서 틀렸는지 알려 주고, 읽을 수 있는 앞부분은 보여 준다.
- **EUC-KR 처리**:
  - 브라우저는 EUC-KR 인코딩을 지원하지 않는다. 그래서 처음 쓸 때 `TextDecoder("euc-kr")`로 A1~FE × A1~FE 영역을 훑어 역방향 표를 만든다.
  - 브라우저 디코더는 실제로 CP949라 확장 영역도 풀지만, 표에는 KS X 1001 범위만 넣는다. 그래서 "똠"은 EUC-KR "없음"이다.
- UTF-8·UTF-16 해독은 오류 위치를 알려 주려고 직접 구현했다.

## 색상 스포이트 (`/color-picker`)

- **이미지 넣기**: 파일 선택, 끌어다 놓기(페이지 어디든), Ctrl/⌘+V 붙여넣기로 넣는다.
- **이미지에서 뽑기**:
  - 11×11 픽셀 돋보기가 포인터를 따라다닌다.
  - 클릭하면 그 픽셀 색을 HEX·RGB·HSL(CSS Color 4 공백 구문)로 보여 주고, 줄을 누르면 복사한다.
- **화면에서 뽑기**: EyeDropper API가 있는 데스크톱 크로미움에서만 버튼을 보여 준다. 지원 여부는 `useSyncExternalStore`로 읽어 hydration 불일치를 피했다.
- **큰 이미지**: iOS Safari 캔버스 한도(약 16.7M 픽셀) 때문에 긴 변 4096px·1,600만 픽셀 안으로 줄여 그린다(`fitWithin`).
- **최근 뽑은 색**: 최근 10개를 메모리에만 둔다.

## 팔레트 추출기 (`/palette-extractor`)

- 긴 변 200px로 줄인 이미지에서 색을 뽑는다.
- 네모네모빔의 `quantizeMedianCut`(대표색이 실제로 이미지에 있던 색)을 `_shared/quantize.ts`로 옮겨 같이 쓴다. 비율은 픽셀 수 기준으로 많은 순서다.
- 색 개수는 3~12개이고 기본은 6개다.
- 결과는 HEX 하나씩 복사하거나, CSS 변수·JSON으로 한 번에 복사한다.
- 알파 128 미만 픽셀은 계산에서 뺀다. 전부 투명하면 안내 문구를 띄운다.

## 리뷰 후 수정

- 붙여넣기 가드가 모든 `INPUT`을 건너뛰어서, 슬라이더에 포커스가 있으면 이미지 붙여넣기가 무시됐다. 글자 입력칸만 건너뛰도록 `isTextEntryTarget`을 두었다.
- 드롭 영역 밖에 이미지를 놓으면 브라우저가 파일을 열어 작업이 사라졌다. `window`에서 `dragover`·`drop`을 받아 처리한다.
