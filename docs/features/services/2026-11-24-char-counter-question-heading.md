# 글자수 세기 — 문항 칸을 상자 없는 제목줄로

문항 칸과 본문 입력칸이 둘 다 흰 상자(`PANEL`)여서 화면에 비슷한 무게의 상자가 두 개 나란히 보였고, 시선이 어디에 둬야 할지 흩어졌다. 문항은 "보면서 쓰는 질문"이고 본문은 "쓰는 곳"이라 역할이 다르므로 생김새도 다르게 했다.

## 바뀐 점
- 문항 칸의 테두리·흰 배경을 없애고 페이지 배경 위의 제목줄로 그린다. 흰 상자는 본문 입력칸 하나만 남는다.
- 작은 '문항' 라벨 대신 굵은 `Q.`를 단다. 화면 낭독기용으로 `sr-only` '문항'을 함께 둔다.
- 문항 글자는 15px semibold로 키워 질문 제목처럼 읽히게 했다. placeholder는 보통 굵기.
- hover·포커스 때만 배경을 아주 옅게(`bg-point/[0.03]`·`[0.04]`) 칠해 입력 가능한 영역임을 알린다. 처음엔 왼쪽 세로 막대를 뒀다가 뺐다.
- 문항 지우기(×)는 평소 숨기고(`opacity-0`) 영역 hover 때 보인다. hover가 없는 터치·키보드 사용자를 위해 `group-focus-within`·`focus-visible`에서도 보이게 했다.
- 사용 안내(`guide.ts`)의 "'문항' 칸"을 "'Q.' 줄"로 고쳤다.
